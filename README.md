# Tasky - Flutter Task Management App

A simple and efficient task management application built with Flutter.

## Features

- Create, edit and delete tasks
- Mark tasks as complete/incomplete 
- Clean and intuitive user interface
- Provider state management
- Cross-platform support (iOS, Android, Web)

## Getting Started

### Prerequisites

- Flutter SDK v3.0+
- Dart v3.0+
- Android Studio / VS Code
- Android SDK / Xcode (for iOS development)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/kjarj54/Tasky.git
```

2. Navigate to project directory:
```bash 
cd tasky
```

3. Install dependencies:
```bash
flutter pub get
```

4. Run the app:
```bash
flutter run
```

## Architecture

The app follows a clean architecture approach with:

- [`lib/screens`](lib/screens) - Contains all the UI screens and their logic
- [`lib/providers`](lib/providers) - Manages application state using Provider package
- [`lib/models`](lib/models) - Defines data structures and business logic
- [`lib/widgets`](lib/widgets) - Houses reusable UI components
